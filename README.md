# BroadbandX Backend API

BroadbandX Customer & Billing Management System backend API built with Express, Sequelize, PostgreSQL (Neon), and JWT Authentication.

---

## Deployments & Domains

- **Dev Backend API**: [https://broadbandx-be.vercel.app/api](https://broadbandx-be.vercel.app/api)
- **Dev Frontend (CNAME)**: [https://broadbandx.vercel.app](https://broadbandx.vercel.app)
- **Local Dev Server**: `http://localhost:3000`

---

## Getting Started

### Install Dependencies
```bash
npm install
```

### Seed Database
```bash
npm run seed
```

### Run Locally
```bash
npm run dev
```
